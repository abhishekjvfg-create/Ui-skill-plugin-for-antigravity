# visual qa

## Goal
Compare intent and implementation with controlled screenshots.

## Workflow
1. Capture the same viewport, content and animation state for comparisons. Freeze motion and wait for fonts/images. Inspect major composition before micro-adjustments.

2. Check spacing rhythm, type scale, contrast, alignment, crop, light direction and visual density. Use difference overlays as diagnostics, not a substitute for judgment.

3. Prioritize issues by user impact. Fix one class of issues at a time, recheck other breakpoints, and cap revisions at the agreed iteration budget.

## Acceptance / stop condition
Provide representative screenshots and a short resolved/unresolved list; do not claim pixel-perfect parity without a defined reference and measured comparison.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

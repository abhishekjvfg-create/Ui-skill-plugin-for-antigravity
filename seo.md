# seo

## Goal
Make meaningful content discoverable without hiding it in canvas.

## Workflow
1. Write a specific page title, description and canonical URL only when the production URL is known. Keep essential copy and links in HTML.

2. Use descriptive headings, appropriate structured data for actual facts and crawlable navigation. Do not invent ratings, offers or organization details.

3. Check image alt text, robots rules and real HTTP status codes. Keep staging/private environments out of search when required.

## Acceptance / stop condition
Rendered content is meaningful without 3D; metadata reflects real content and production routes.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

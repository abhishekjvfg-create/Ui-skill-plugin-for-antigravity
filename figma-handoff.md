# figma handoff

## Goal
Provide design-system artifacts without pretending to be the Figma application.

## Workflow
1. Export semantic tokens, component anatomy, variants, states, spacing, responsive rules and asset filenames. Map code components to design concepts; name regions and reusable pieces consistently.

2. Use SVG for original vector graphics and JSON for token exchange. Include dimensions and constraints, not just screenshots. If a real Figma MCP/plugin is authorized, inspect its schema and permissions before using it.

3. Do not claim a native .fig file was generated by this toolkit. Editable SVG, CSS and JSON are the supported local artifacts. Keep provenance and licenses with exported assets.

## Acceptance / stop condition
A designer can reconstruct the grid and component states from the handoff without guessing sizes or colors.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

# accessibility

## Goal
Build task-complete experiences for diverse input and perception needs.

## Workflow
1. Use native semantic elements, labels, headings, landmarks and a skip link. Avoid tabindex greater than zero. Ensure focus is visible and not covered by sticky UI.

2. Keep meaningful canvas information in ordinary HTML. Use polite status updates for changes, not blanket aria-live on entire pages. Never mark screen-reader-required text aria-hidden.

3. Check keyboard paths, 200% zoom, contrast, reduced motion, dialogs, forms and error recovery. Automated scans supplement, not replace, manual and assistive-technology checks.

## Acceptance / stop condition
Primary user journeys work without a mouse and without seeing the canvas.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

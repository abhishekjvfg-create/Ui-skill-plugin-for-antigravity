# progressive enhancement

## Goal
Keep the useful experience available when optional effects fail.

## Workflow
1. Render content, navigation and a static visual before loading 3D. Enhance only after successful initialization.

2. Handle CDN/import errors, absent WebGL, reduced motion and context loss. A decorative failure must not disable purchasing, reading or contact tasks.

3. Test with JavaScript disabled where core static content is concerned, block the CDN and simulate WebGL failure. Label interactive features that require JavaScript.

## Acceptance / stop condition
Core information and navigation remain available; optional failures produce an honest usable fallback.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

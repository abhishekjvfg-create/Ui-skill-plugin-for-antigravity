# Practical prompts

Mention **atlas-studio** explicitly if the agent does not select the skill automatically. Give one business goal and real content when possible. These prompts activate agent workflows; the local CLI itself is not an LLM.

## Premium product site

> Use atlas-studio to build an original premium beverage website. Inspect my existing stack first. Choose an expressive but readable type system, restrained color palette and metallic product scene. Use licensed brand assets I provide; otherwise label procedural geometry as a placeholder. Include functional navigation, product detail sections, FAQ and an honest contact flow. Test desktop/mobile, reduced motion, keyboard navigation and WebGL failure. Maximum three refinement passes; ask before costs or deployment.

## 3D-background portfolio

> Use atlas-studio. Create a premium creative developer portfolio with a ribbon-tunnel or orbital-dust background. Keep project case studies in semantic HTML with clear links. The background must stay behind readable content, pause offscreen, honor reduced motion and fall back to a static visual. Search the library, customize rather than copying the starter unchanged, and report measured draw calls.

## Food motion

> Use atlas-studio for a restaurant experience with a warm editorial design and ingredient-burst composition. Prefer lightweight procedural geometry for the interactive draft. If photoreal liquids are needed, explain the asset/generation requirements and ask permission first. Include a static fallback, clear menu and truthful reservation CTA.

## Luxury skincare

> Use atlas-studio to build a tactile skincare product page. Select a bottle-studio scene, soft neutral surfaces, high-contrast serif display type and readable body text. Avoid unsupported product claims. Build responsive product details and accessible controls before adding motion. Use two font families at most and document their licenses.

## Hindi typography

> Use atlas-studio to choose typography for a Hindi/English brand. Search real Devanagari-capable fonts, inspect weights and pairings, and test both scripts. Do not add inappropriate letter spacing to Hindi. Export color/spacing/type tokens and show samples at mobile widths.

## Existing-app polish

> Use atlas-studio to audit and polish this existing website without changing its framework. First list the five highest-impact issues with screenshots. Fix the primary flow, then typography, spacing, responsive behavior and motion. Run existing tests and targeted browser checks. Preserve unrelated changes.

## Bug repair

> Use atlas-studio's bug-fixing workflow. Reproduce the reported bug, capture the first wrong state, write a focused regression test, patch the smallest relevant code and rerun checks. Do not treat the heuristic audit command as proof of correctness. Summarize cause, fix and remaining limitations.

## Stitch design-to-code

> Use atlas-studio and my already authorized native Stitch MCP connection. First discover the actual available tools and schemas, then list my projects. Ask which project/screen to use. Extract tokens and layout, build semantic responsive components, and compare screenshots. Ask before any new generation or paid call; do not invent image-generation capabilities.

## Bounded detail pass

> Use atlas-studio's micro-detail and visual-qa workflows. Spend at most three passes on this page. Check baseline alignment, heading wrap, control states, border consistency and 360/768/1440px layouts. Save a checkpoint if blocked. Do not generate thousands of arbitrary variations or claim unlimited reasoning.

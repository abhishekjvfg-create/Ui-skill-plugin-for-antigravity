# ui composition

## Goal
Design compositional hierarchy with responsive semantic components.

## Workflow
1. Choose a content grid and maximum reading width. Establish dominant, supporting and quiet regions. Put content in logical DOM order before visual placement.

2. Use one h1 per page, descriptive headings, short readable lines and a meaningful CTA. Combine at most a few component families, not every catalog sample. Prefer asymmetry with a clear anchor over random masonry.

3. Implement empty, loading and failure states wherever live data will appear. Label demo content. Check that repeated cards preserve spacing and alignment with long titles.

## Acceptance / stop condition
The layout works with realistic copy, twice-length translations and one missing image.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

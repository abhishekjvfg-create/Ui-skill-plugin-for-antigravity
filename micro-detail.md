# micro detail

## Goal
Polish meaningful small details after the primary flow works.

## Workflow
1. Create a punch list: baseline alignment, optical centering, border consistency, line breaks, icon size, button text, input spacing and focal point cropping.

2. Inspect one section at a time at 100% and 200% zoom. Align related edges, use tabular numerals for metrics and keep punctuation/capitalization consistent. Avoid arbitrary one-pixel offsets until the underlying layout is correct.

3. Fix the highest-visibility issues first. Record before/after screenshots and stop when the agreed budget is reached. Do not generate thousands of imperceptibly different candidates.

## Acceptance / stop condition
Each change has an observable reason; no regression in keyboard access or mobile wrapping.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

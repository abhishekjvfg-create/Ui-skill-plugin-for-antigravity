# motion choreography

## Goal
Choose purposeful, accessible timing instead of constant movement.

## Workflow
1. Search 600 motion recipes built from 24 keyframe families, five durations and five amplitudes. They are executable Web Animations API presets, not 600 independently hand-animated films.

2. Use 180–300ms for small feedback, longer entrances only when useful. Stagger related items subtly. Keep repeated motion finite or give a pause control. Prefer transform/opacity over layout properties.

3. Clip/blur can cause paint costs: test them. Avoid flashing and rapidly alternating contrast. Preserve final readable state after cancellation and reduced-motion changes.

## Acceptance / stop condition
Animation communicates state or hierarchy, does not delay primary actions, and can be stopped.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

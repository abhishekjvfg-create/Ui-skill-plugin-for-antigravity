# stitch

## Goal
Use authorized Google Stitch designs through the native Antigravity MCP connection.

## Workflow
1. Official setup reference: https://codelabs.developers.google.com/design-to-code-with-antigravity-stitch . In the supported Antigravity surface, open MCP Servers, install the official Stitch integration and configure the user-created key privately. CLI configuration may differ by version; consult its current MCP documentation, never invent a config path.

2. Ask the connected client to list available Stitch tools and inspect their live argument schemas. First perform an authorized read such as listing the user's projects. Select the user's actual project; do not invent project or screen IDs.

3. Before generation, confirm brief, desktop/mobile targets, budget and number of candidates. Request only supported outputs. Extract tokens, compare screens, then translate into semantic modular code. Review generated HTML/SVG/assets for safety and licensing before use.

## Acceptance / stop condition
If no connection/key is present, stop external calls, produce the stitch handoff brief and continue with local original assets. This pack does not ship an authenticated MCP client or guarantee an image-generation tool. Never claim Stitch was tested without a live authorized session.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

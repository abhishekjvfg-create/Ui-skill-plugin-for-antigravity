# quality loop

## Goal
Work persistently within explicit limits rather than pretending to think forever.

## Workflow
1. Set defaults: three iterations, thirty minutes, zero paid generation calls. User or platform limits take precedence. Break the task into observable milestones with acceptance criteria.

2. For each iteration: inspect evidence, choose the highest-impact issue, implement a bounded change, run checks and record the result. Do not repeatedly regenerate full projects when a targeted patch suffices.

3. When blocked, summarize cause and required input. When the budget is reached, save a checkpoint with files changed, last commands, known failures and next action. Ask before extending scope or costs.

## Acceptance / stop condition
No infinite loops, hidden autonomous spending, fabricated completion or claims of unlimited model reasoning.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.

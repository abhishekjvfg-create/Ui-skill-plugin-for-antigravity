# svg graphics

## Goal
Create original lightweight vector art for backgrounds and brand-adjacent graphics.

## Workflow
1. Use the graphic command for deterministic orbit, grid, waves or petals compositions. Change seed and palette intentionally; these are original procedural graphics, not stock assets.

2. Keep viewBox responsive. Include a title when meaningful or aria-hidden when decorative. Remove scripts, external references and foreignObject from untrusted SVG before embedding.

3. Prefer simple paths and gradients over huge filters. Test scaling and contrast under real text. Do not invent a brand logo that closely resembles a protected mark.

## Acceptance / stop condition
SVG scales cleanly, has appropriate alternative text and contains no external tracking or executable payload.

## Evidence to retain
Relevant file paths, exact commands actually run, observed outcomes and unresolved limitations. Ask before destructive changes or external paid operations.
